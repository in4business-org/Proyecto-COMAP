# GPC · frontend

React 19 + Vite + Tailwind 4. Guía visual y componentes: [DESIGN_GUIDE.md](DESIGN_GUIDE.md).

```bash
npm install
npm run dev     # servidor local
npm run lint    # tiene que quedar sin errores antes de cada commit
npm run build
```

Variables: `VITE_API_URL`, `VITE_COGNITO_USER_POOL_ID`, `VITE_COGNITO_CLIENT_ID`.
