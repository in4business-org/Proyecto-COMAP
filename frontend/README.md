# GPC · frontend

React 19 + Vite + Tailwind 4. Guía visual y componentes: [DESIGN_GUIDE.md](DESIGN_GUIDE.md).

```bash
npm install
npm run dev     # servidor local (necesita el backend en :3001)
npm run demo    # sin backend, con datos de ejemplo
npm run lint    # tiene que quedar sin errores antes de cada commit
npm run build
```

Variables: `VITE_API_URL`, `VITE_COGNITO_USER_POOL_ID`, `VITE_COGNITO_CLIENT_ID`.

Cómo ver los cambios en local (modo demo o con backend): [../DESARROLLO_LOCAL.md](../DESARROLLO_LOCAL.md).
